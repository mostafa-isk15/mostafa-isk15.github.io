# Mimu Calendar information site

Public homepage, privacy policy, and terms for an owner-operated email and Calendar assistant.

This repository is **only a static information site**. It must not contain mailbox contents, private Calendar entries, OAuth client configuration, access/refresh tokens, app passwords, local assistant history, or API keys. The actual integration runs separately in the owner's local assistant environment.

- `index.html`: app purpose and permissions
- `privacy.html`: data access, processing, retention, and revocation
- `terms.html`: private-use boundaries and reliability limitations

GitHub Pages serves these files as static HTML. No third-party fonts, analytics, scripts, forms, or application backend are included.
